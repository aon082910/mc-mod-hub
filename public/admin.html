Admin login

Default password is admin unless overridden by the ADMIN_PASSWORD environment variable at first boot. Change it below after logging in.

API Keys

Get a free key at console.curseforge.com/#/api-keys (requires a free Eternal / CurseForge Core account).
Create one in Google Cloud Console → APIs & Services → Credentials, with the "YouTube Data API v3" enabled.

Sources

MC-Addons.com and MCPEDL aren't scraped — MC-Addons' own robots.txt blocks automated search, and MCPEDL's results load via client-side JS with nothing in the raw page to scrape. Both still show up as quick "search on site" links on the search page.

Performance

How long search results and the notice board are cached before re-querying sources. Lower = fresher but slower and more load on the (rate-limit-sensitive) scraped sites. Set to 0 to disable caching entirely.

Server Integration

Lets you click "Install to my server" on a search result (Modrinth/CurseForge only) to download it straight into a mounted mods folder, and adds an Update Checker that scans installed .jar files by content hash (not filename) against Modrinth and CurseForge to flag outdated ones.
Requires mounting your Minecraft server's mods folder into this container at /mods (see the Path config in the Unraid template, or add a volume manually). Toggling this on without that mount will show "not mounted" instead of doing anything destructive.
